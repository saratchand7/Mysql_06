Queries and Sub-Queries
=======================

what is subquery?
----------------

a subquery is a query inside another query
it is written inside parenthesis() and its result is used by the outer query.


it is also called as
inner query
nested query
inner select



purpose of subquery
-------------------
1.to break down complex problems into smaller queries.
2.to use the result of one query as input to another.
to avoid multiple steps(Write in a single query instead of temp tables).

general syntax
===============

select column-list from table
where column OPERATOR(select column from table where condition);

types of sub-queries
====================

1. single row-subquery
-----------------------

-->single row subquery returns exactly one row and one column. they use comparison operators like =,>,<,<=,>=,!=

characteristics:- 
---------------
1.1 returns only one value.
1.2 can use single-value comparison operators.
1.3 if subquery returns no rows or multiple rows it causes an error

syntax:-
-------
select columns
from table
where column operator(select column from  table where condition);


2. multi-row-subquery
---------------------
(a) Multi-Row Subquery IN
---------------------

-->a multirow subquery returns more than one row. the in operator is used to when you want to compare a value with multiple values returned by the subquery.

characteristics
---------------
returns multiple rows.
use the IN Operator.
checks weather a value exists in the list returned by the subquery.
Equivalent to multiple OR Condition.
most commonly used for matching values.

syntax
------

select column from a table
where column IN(select column from table where condition);

()b Multi-Row Subquery (ANY/SOME)
-----------------------------------

--> multi-Row subqureies returns multiple rows. when usring ANY or some. the condition is true if it matches at least one value returned by the subquery.

characteristics
---------------
returns multiple values.
ANY and SOME are interchangeable.
condition is true if any of the values satisfy the condition.
often used with IN,>Any,<ANY,>=ANY...etc

syntax
------
select column from table
where colum OPERATOR any/SOME(Select Column from table where conditions);

(c) Multi-Row Subquery ALL
--------------------------

--> the ALL operator means the condition must be true for all values returned by the subquery.

characteristics
---------------

conditions must be true for all values in the subquery result
often used with >ALL,<ALL,>=ALL,<=ALL
>ALL means greater than the maximum value
>ALL means less than minimum value.

syntax
------
select column from table
where column Operator all(SELECT COLUMN FROM TABLE WHERE CONDITION);

3. nested subquery
-------------------

--> nested subqueries are subquries within subqueries. they can be multiple levels deep
and are executed from innermost to the outermost.

characteristics
---------------

multiple levels of nesting
inner queries execute first.
can combine different types of subqueries
useful for complex conditions

syntax
----------

select column-list from table
   where column = (select column  from table where column = (select column from table where condition));

4. corelated subquery
---------------------

--> corelated subqueries are subqueries that reference columns from outer query.
unlike regular subqueries that execute once. corelated subqueries execute once per each row processed by the outer query.

characteristics
---------------

reference column from outer query.
executes multiple times(once per outer row).
cannot be execute independently.
often used with Exists/NOT EXISTS.
generally slower than non-corelated subqueries.

syntax
------
select column from table1 outer_alias
   where condition(select column from table2 inner_alias
                            where inner_alias.column=outer_alias.column);


5. exist/not exist subquery
---------------------------

Exists is used to test weather a subquery returns any rows. it returns TRUE if the subquery returns at least one row. FALSE otherwise.
NOT EXISTS returns TRUE if the subquery returns no rows.

characteristics
---------------

returns TRUE/FALSE(Boolean result)
more efficient that IN For large datasets.
often used with corelated subqueries.
stops execution as soon as first match is found.
select clauses in EXISTS doesn't matter(often use SELECT 1).

syntax
------

SELECT COLUMNS FROM Table1
where exists(select 1 from table2 where condition);

syntax-2
------

SELECT COLUMNS FROM Table1
where NOT-EXISTS(select 1 from table2 where condition);
