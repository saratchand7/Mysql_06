VIEWS
A VIEW IS A VIRTUAL TABLE CREATED FROM THE RESULT OF SELECT QUERY.
IT DOSEN'T NORMALLY STORES THE ACTUAL DATA SEPARATELY INSTEAD IT STORES THE SQL QUERY AND WHENEVER YOU ACESSES THE VIEW , MYSQL RETRIEVES THE DATA FROM THE UNDERLYING TABLES.

WHY DO WE NEED VIEWS?
SIMPLIFY COMPLEX QUERIES.
REUSE QUERY LOGIC.
DATA SECURITY.
Simplified reporting.

Advantages of views:
Security
Simplicity
Reusability

(NOTES LINK:https://tinyurl.com/MySQLPFSDA-06-Notes)



DIFF B/W TABLE AND VIEW
TABLE PHYSICALLY STRORES DATA 
VIEW IS VIRTUAL TABLE BASED ON QUERY.

CAN STORES RECORDS DIRECTLY.
USUALLY DOESN'T STORE SEPERATE RECORDS.

CREATE USING CREATE TABLE
CREATE USING CREATE VIEW.

IT CONTAIN ALL TABLE DATA
CAN SHOW SELECTED ROES/COLUMNS.

USED FOR PERMANENT DATA STORAGE.
MAINLY USED FOR ABSTARACT,SECURITY,AND REUSABLE QUERIES.

CREATE VIEW SYNTAX:
CREATE VIEW VIEW_NAME AS
SELECT COLUMN FROM TABLE
WHERE CONDITION.

ALTERINING VIEW
ALTER VIEW VIEW_NAME AS
SELECT NEW_COLUMN FROM NEW_TABLES
WHERE NEW_CONDITIONS;

DROP A VIEW
DROP VIEW VIEW_NAME;

mysql> CREATE VIEW VW_DEPARTMENT_SALARY_SUMMARY AS
    ->      SELECT D.DEPT_NAME,
    ->      COUNT(E.EMP_ID)AS TOTAL_EMPLOYEES,
    ->      SUM(E.SALARY)AS TOTAL_SALARY,
    ->      AVG(E.SALARY)AS AVERAGE_SALARY
    ->      FROM EMPLOYEES E
    ->      JOIN DEPARTMENTS D ON E.DEPT_ID=D.DEPT_ID
    ->      GROUP BY D.DEPT_NAME;
